IP 归属地查询工具

本工具是一款免费在线的 IP 归属地查询服务。打开页面即可自动显示你当前的公网 IP 地址及对应地理位置，也可以手动输入任意公网 IPv4 或 IPv6 地址，快速查询所在的国家、省份、城市、运营商（ISP）、ASN、时区等详细信息。

适用于排查网络连接异常、定位服务器节点、了解访客来源地、SEO 分析、网络运维调试等场景。

常见问题

查询出来的 IP 归属地准确吗？

本站通过后端代理多数据源查询并自动降级，返回国家、省份、城市、运营商、ASN 等信息。运营商级归属地一般较准确，精确到区县级别取决于数据库精度，结果仅供参考。

支持 IPv6 查询吗？

支持。工具同时支持 IPv4 与 IPv6 公网地址，在输入框中直接输入即可查询。

我的 IP 会被保存吗？

不会。查询结果仅用于本次展示，本站不存储您的 IP 地址与查询历史，可放心使用。

为什么查询显示的位置和我不一致？

当使用代理、VPN 或 CDN 时，查询到的是其出口 IP 的归属地，与本地实际物理位置不同，属于正常现象。
