IP 归属地查询工具

本工具是一款免费在线的 IP 归属地查询服务。打开页面即可自动显示你当前的公网 IP 地址及对应的地理位置，也可以手动输入任意公网 IPv4 或 IPv6 地址，快速查询其所在的国家、省份、城市、运营商（ISP）、ASN、时区等详细信息。

适用于排查网络连接异常、定位服务器节点、了解访客来源地、SEO 分析、网络运维调试、以及日常的 IP 信息查询等场景。

使用步骤

1. 打开页面，顶部卡片自动显示你的当前 IP 及归属地。
2. 如需查询其他 IP，在上方输入框输入公网 IPv4/IPv6 地址。
3. 点击「查询」按钮（或按回车），即可查看对应 IP 的国家、省份、城市、运营商等详细信息。
